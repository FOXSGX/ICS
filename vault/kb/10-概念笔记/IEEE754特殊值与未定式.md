# IEEE 754 特殊值与未定式

## 来源与速查

[教材](../../../resources/textbook/计算机系统%20基于%20x86+Linux%20平台%281%29.pdf) 第 2 章 2.3.3 节，印刷页 34–35（PDF 第 49–50 页），表 2.2 与表 2.3：阶码全 0、尾数全 0 表示 ±0；阶码全 1、尾数全 0 表示 ±∞；阶码全 1、尾数非 0 表示 NaN。表 2.3 列出可产生 NaN 的未定式。

## 原始疑问与修正

用户最初认为 `+∞ + (−∞)` 返回 NaN 只是规定，规定为 `+∞` 似乎也可以。用趋近过程检验：`n + (−n)=0`，`2n + (−n)→+∞`，`n + (−2n)→−∞`。仅知道两边分别趋于正、负无穷，无法确定和的唯一结果；强行返回正无穷会误判其他情况。

同理，`n/n→1` 与 `2n/n→2` 说明 `+∞ / +∞` 没有唯一数值；用户随后正确判断不能固定为 1。

## 边界与下一步

IEEE 754 用 NaN 表示这些运算没有确定的普通数值结果；不能把所有涉及无穷大的运算都当成 NaN，例如有限正数加正无穷大仍得到正无穷大。后续可结合实际浮点运算检验特殊值传播。
