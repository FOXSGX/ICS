# ICS 学习工作区

此目录用于持续整理 ICS 课程的作业、实践、原始资料与学习记录。已加入一本扫描版教材，尚无作业或可运行项目；“ICS”的课程全称与学习范围仍待用户确认。

公开仓库不包含扫描版教材 PDF。使用本地教材时，将文件放在 `resources/textbook/`；[来源登记](vault/kb/SOURCES.md) 保留了本地文件名与核对记录。

从 [INDEX.md](INDEX.md) 进入，再查看 [当前任务](vault/projects/ICS/TODOS.md)。如使用 Obsidian，请将 `C:\Users\IMAFOX\Desktop\CODES\ICS` 作为 Vault 打开；模板目录已设为 `vault/kb/90-模板`。

- `coursework/assignments/`：课堂作业、原题与提交产物。
- `practice/`：自主练习、复现、实验代码或数据。
- `resources/textbook/` 与 `resources/slides/`：原始教材与课件。
- `vault/projects/ICS/`：目标、任务和知识缺口。
- `vault/notes/`：过程日志。
- `vault/kb/`：可复用知识、来源笔记、实验与复习记录。

新增资料后，在 [来源登记](vault/kb/SOURCES.md) 登记来源，并更新 [索引](INDEX.md) 中对应入口。运行命令应依据实际加入的项目再记录。
